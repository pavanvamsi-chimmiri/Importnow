Let's ImportNow

End-to-end project document — China to India import website

1. What this website is

Let's ImportNow is a complete website for importing goods from China to India. A client chooses the product. The team finds verified factories, inspects them in person, checks quality before the container is sealed, ships by sea or air, clears customs and GST in India, and unloads at the shop, warehouse, villa, or site.

The product is built for Indian businesses that want to import without guessing: one-piece MOQ on many items, an on-ground team, and a registered company in Shanghai for contracts and payments. Offices are in Hyderabad and Shanghai.

3. How we developed it

We designed and coded the site as one product: brand, layout, copy, motion, and a live deployment. Work followed this path.

  1. Brand first. Named the product Let's ImportNow. Drew a cargo-ship mark for the logo and the browser tab. Set a China-red / India-saffron / India-green palette on an ocean-navy background, with a thin tricolor bar on every page.
  2. Layout and type. Built a dark, full-width marketing layout. Headings use Sora; body text uses Inter. Cards sit on glass-style panels with a gold edge so the page feels like one brand, not a set of blocks.
  3. China and India ships. Illustrated a China cargo ship (red hull, Chinese flag, CHINA on the side) and an India cargo ship (green hull, tricolor stripe, Indian flag). They sail on the hero route Shanghai → Chennai and on every recently-delivered card.
  4. Sections and copy. Wrote and coded each homepage block from real service copy: sourcing hubs, factory visits, licence details, Canton Fair trips, client jobs, FAQs, and the quote form.
  5. Interaction. Wired smooth-scroll navigation, a mobile menu, an auto-playing journey with a day counter, an FAQ accordion, Sign in / Sign up, and quote buttons that jump to contact.
  6. Responsive check. Tuned desktop, tablet, and phone so text does not overlap and the menu still works on a small screen.
  7. Ship it. Stack is Next.js, React, TypeScript, and Tailwind. The live site is on Vercel; the source is on GitHub.

5. What the product offers

The website explains the full import path, not only a homepage slogan. Sourcing covers Yiwu, Guangzhou, Shenzhen and Foshan. Quality is checked before the container is sealed. Freight can be a full container, a shared container, or air cargo. Customs, duties and GST are handled at Indian ports. Delivery is to the door. Many products can start at one piece, so a new importer does not need a full container on day one.

Proof on the page: 500+ businesses served, a large Instagram community, a Shanghai-registered company, and four recent jobs (villa furniture, a supermarket in Adilabad, a convention centre, and smart desks). Canton Fair trips are listed with visa, hotel, Indian food and factory visits so a buyer can walk the market with the same team.

7. Features that work

  • Menu links scroll smoothly to the matching homepage section on desktop and on the phone menu.
  • Get a free quote buttons take the visitor to the contact form. The form collects name, city, category, quantity, budget, and details.
  • How it works steps play through on their own and can be clicked. The bar shows origin, destination, and day.
  • FAQ items open and close. The first question starts expanded.
  • Sign in and Sign up sit in the header. After login the header greets the visitor by name. Sign out returns the header to Sign in / Sign up.
  • City names scroll in a marquee. Hover states and button transitions are in place.
  • Phone, tablet, and desktop layouts keep the page readable, with no sideways scroll.

8. How a visitor uses the site

Land on the hero, read the offer, and scroll the China → India route. Use the header to jump to services, the six-step journey, product categories, China trips, or contact. Fill the quote form with the product they want to import. Optional: create an account or sign in to come back later. On a phone the same path is in the hamburger menu. The six-step journey is: source the factory, inspect samples, quality check and loading, ocean freight, customs clearance, then doorstep delivery.

9. Technology

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide React, Sora and Inter. Shared chrome lives in components; each homepage block is a section; all service copy lives in one constants file so the site can be updated in one place.

10. Tools we used

Cursor

The editor and coding agent used to design the pages, write the React/Next.js code, restyle the UI, and keep the GitHub repo in sync.

Playwright

Used to open the site in a real browser, check desktop and mobile layouts, capture screenshots, and print this two-page PDF.

Vercel

Hosts the production website. Every push to GitHub builds the Next.js app and publishes it at importnow.vercel.app.

GitHub

Stores the source code so the project can be cloned, reviewed, and redeployed. Vercel pulls the site from this repository.

Let's ImportNow

Project summary — China to India import website (hiring assignment)

1. What this project is

ImportNow asked candidates to recreate their concept website from scratch using AI tools, then submit a live link, source code, and a short note on the tools used.

We built a full Next.js website with the same sections and copy as the reference, then restyled it as Let's ImportNow so it does not look identical. Delivery cards show a China cargo ship and an India cargo ship.

3. What we did

  1. Studied the full reference website (every homepage section, desktop and mobile).
  2. Created a Next.js + TypeScript + Tailwind app with reusable components.
  3. Implemented every section: hero, services, journey, industries, Shanghai licence, China trips, projects, testimonials, FAQ, contact, footer.
  4. Made navigation, WhatsApp contact, the quote form, FAQ accordion, and mobile menu actually work.
  5. Changed the UI from a lookalike into Let's ImportNow: tricolor (China red, saffron, India green), new logo, ocean background.
  6. Added China-flag and India-flag cargo ships on the recently-delivered cards and in the hero.
  7. Ran the site on localhost:3000 and deployed it to Vercel.
  8. Pushed the source to GitHub.

4. Website sections

  • Header — Let's ImportNow logo, links, Get a free quote, mobile menu.
  • Hero — “Let's import directly from China”, stats, globe, Shanghai → Chennai ships.
  • Services — sourcing, inspection, quality, shipping, customs, doorstep delivery.
  • How it works — six steps from factory to door, with shipment progress.
  • What we import — furniture, electronics, EV, lighting, supermarket, machinery.
  • Shanghai licence — registered China company details.
  • China trips — Canton Fair trips and what is included.
  • Recently delivered — four client jobs with China ship and India ship artwork.
  • Stories, FAQ, Contact — reviews, accordion FAQ, WhatsApp form.

5. Technology

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide React, Sora and Inter fonts. Hosted on Vercel. Built with Cursor. Reference pages were inspected with Playwright.

6. How to run

git clone https://github.com/pavanvamsi-chimmiri/Importnow.git

npm install

npm run dev → open http://localhost:3000

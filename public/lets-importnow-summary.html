Let's ImportNow

China to India import website — project summary

1. What this project is

Let's ImportNow is an end-to-end import service from China to India. A client chooses the product; the team sources factories, inspects them, ships the goods, clears customs, and delivers to the door through a registered company in Shanghai.

This website presents that service with a Let's ImportNow brand, China and India cargo ships, and working quote, WhatsApp, and navigation flows.

3. What we did

  1. Built a Next.js + TypeScript + Tailwind website for the full import journey.
  2. Implemented hero, services, journey, industries, Shanghai licence, China trips, projects, testimonials, FAQ, contact, and footer.
  3. Made navigation, WhatsApp contact, the quote form, FAQ accordion, and mobile menu work.
  4. Designed Let's ImportNow with a tricolor palette, ship logo, and a custom tab icon (no default Next.js “N”).
  5. Added China-flag and India-flag cargo ships on delivered-job cards and in the hero.
  6. Deployed the site and published the source on GitHub.

4. Website sections

  • Header — Let's ImportNow logo, links, Get a free quote, mobile menu.
  • Hero — headline, stats, globe, Shanghai → Chennai ships.
  • Services — sourcing, inspection, quality, shipping, customs, doorstep delivery.
  • How it works — six steps from factory to door, with shipment progress.
  • What we import — furniture, electronics, EV, lighting, supermarket, machinery.
  • Shanghai licence — registered China company details.
  • China trips — Canton Fair trips and what is included.
  • Recently delivered — four client jobs with China ship and India ship artwork.
  • Stories, FAQ, Contact — reviews, accordion FAQ, WhatsApp form.

5. Technology

Next.js 16, React 19, TypeScript, Tailwind CSS 4, Framer Motion, Lucide React, Sora and Inter fonts. Hosted on Vercel.
